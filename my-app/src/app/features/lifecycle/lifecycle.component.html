🔄 Lifecycle Hooks

Tap into key moments of a component's life — from creation to destruction

About This Feature

Angular calls lifecycle hook methods at specific moments during a component's creation, update, and destruction. Implement the corresponding interface to use each hook.

  1. ngOnChanges — @Input() values changed
  2. ngOnInit — component initialized (once)
  3. ngDoCheck — custom change detection
  4. ngAfterContentInit — projected content initialized
  5. ngAfterContentChecked — projected content checked
  6. ngAfterViewInit — component view rendered (access @ViewChild)
  7. ngAfterViewChecked — component view checked
  8. ngOnDestroy — just before destruction (cleanup!)
