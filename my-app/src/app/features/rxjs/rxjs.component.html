🌊 RxJS & Observables

Reactive programming with streams, operators, and automatic cleanup

About This Feature

RxJS is Angular's reactive programming library. It lets you treat events and async data as streams you can compose with operators.

  • Observable — lazy stream of values over time
  • Subject — multicast observable + observer; manually push values
  • BehaviorSubject — Subject with an initial value; replays last value to new subscribers
  • debounceTime — wait for a pause before emitting (e.g., search)
  • distinctUntilChanged — skip duplicate consecutive values
  • scan — accumulate values over time (like Array.reduce)
  • takeUntil — complete when another observable emits (memory-safe unsubscribe)
